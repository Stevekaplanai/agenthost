# Repurpose Post — One Post, Every Platform

You wrote one thing. It worked. Now you extract the most value from it by taking the same core mechanism to every platform — without reposting the same content.

Each platform gets its own native format. Not a copy. A translation.

---

## Phase 1: Load Context

Read `~/.claude/CLAUDE.md` and sub-files (brand-voice.md, icp.md). You need their voice and audience for every adaptation.

If missing: "Set up your content brain first with /brain-builder — the repurposing will sound generic without it."

---

## Phase 2: Understand the Original

The member pastes the post they want to repurpose. Before adapting, extract:

- **Core mechanism:** What's the underlying insight, framework, or story?
- **Strongest moment:** The single line or idea that made this land
- **Proof point used:** The specific result, example, or data that carries the argument

Do this analysis silently — don't show it. Use it to inform each platform version.

---

## Phase 3: Platform Adaptations

Produce all four formats. Each gets its own section. Each is formatted for that platform's native experience.

---

### LINKEDIN

The original may already be LinkedIn-formatted. If so, use this as a refinement — tighten the hook, punch the ending, strengthen the CTA.

If it originated elsewhere, translate it fully:

**Format rules:**
- One sentence per line. Blank line between every paragraph.
- Hook = first 1–2 lines before "...see more" — must create tension without context
- Short paragraphs (1–3 sentences max)
- Specific numbers, not vague claims
- CTA at end — benefit-first ("Get the [thing]") not action-first ("Click here")
- Optional repost line last

[Output the full post — no surrounding labels or headers, just the post text]

### TIKTOK / REELS SCRIPT

Not a post — a spoken script. Written for the ear.

**Format:**

**HOOK (0–3 sec):** [One line. Direct address or bold claim. Under 10 words. This is what someone hears in the first 3 seconds — the thing that stops them from swiping.]

**SETUP (3–10 sec):** [Establish the context in 1–2 sentences. Why this matters to the viewer right now.]

**POINT 1 (10–30 sec):** [First key point. Tight. One idea. Include the specific example or proof if available.]

**POINT 2 (30–50 sec):** [Second point. Build on point 1 or contrast it. Keep moving.]

**POINT 3 (50–70 sec):** [Third point or the payoff. Where the mechanism fully lands.]

**CTA (70–90 sec):** [What they should do next. Keep it one thing. "Follow for part 2" / "Comment [X] if this happened to you" / "Save this for when you need it."]

**Total length:** ~[word count] words / ~[X] seconds spoken
