## Publication Guidelines

### For External Use (Customer-Facing)
- ✅ Use real company names (BarkBox, AML Watcher, The KYB, Isaacs)
- ✅ Include full metrics and dollar figures
- ✅ Lead with outcome (CAC reduction, ROAS improvement)
- ✅ Reference methodology (multi-touch attribution, ICP-first, etc.)
- ⚠️ Anonymize if NDA'd or if client requests confidentiality (flag in metadata)

### For Internal Use (Positioning / Memory)
- ✅ Real names preferred for full context
- ✅ Include both quantitative metrics AND qualitative learning
- ✅ Link to broader strategic patterns (e.g., "attribution is the leverage point")

### For Investor / Funding Materials
- ✅ Use regtech case studies for SMB/mid-market B2B SaaS context
- ✅ Emphasize repeatable pattern (5 case studies, consistent findings)
- ✅ Lead with the thesis: "last-click attribution undervalues demand generation by 2-5x"
- ⚠️ Avoid naming clients if they're early-stage or confidential; anonymize with vertical + metrics instead
