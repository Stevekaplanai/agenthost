---
name: Always send document paths/URLs
description: When creating documents, files, or anything viewable, always include the file path or URL in the final response so the user can access it immediately
type: feedback
---

When creating documents (pitch decks, reports, screenshots, HTML files, etc.), ALWAYS include the full file path or URL in the final response. Don't just say "I created it" — give the user the exact path to open it. This applies to localhost URLs, file paths, generated images, PDFs, presentations, etc.
