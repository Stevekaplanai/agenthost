**Hard requirement learned 2026-06-15:** Hermes refuses tool use below **64,000 tokens** of *runtime* Ollama context. 32768 (the GPU-safe ceiling for an 8GB RTX 4070 Laptop) is NOT enough — Hermes errors out. Caveat for [[hermes-multi-agent-pipeline]] consensus: two local models (llama3.1:8b + qwen2.5:7b) at 64K simultaneously ≈ 28GB mapped — rely on Ollama's idle-unload (4-min TTL) and sequential consensus calls; don't assume both stay resident.
