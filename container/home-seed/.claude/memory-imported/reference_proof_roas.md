ROAS is three different numbers. Label each correctly, never conflate them:

- **3.2:1 (3.2x)** = lifetime AVERAGE across all accounts / $50M+ managed. This is the **headline/featured** ROAS number on stevekaplan.ai (and what the case studies + blog already use). Steve confirmed 3.2 (NOT 4.2) on 2026-05-30.
- **10:1** = sustained top performance at $2M+/mo spend. The GTMVP-canonical figure (gtmvp.com, offer.md). Fine to feature, honestly labeled as "sustained."
- **32:1** = highest single result ever (a PEAK). Do NOT feature it as a lifetime/average number or front-and-center: it reads as outrageous and is un-auditable as an average.
- **36:1** = always wrong, never use.
